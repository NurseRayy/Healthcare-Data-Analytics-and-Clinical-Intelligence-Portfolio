Doctor of Nursing Practice (DNP) prepared healthcare professional showcasing clinical analytics, quality improvement, SQL, Tableau, and data-driven insights to advance healthcare performance while optimizing desired patient outcomes.
## Healthcare Utilization Analysis Dashboard

An end-to-end healthcare analytics project using synthetic Synthea data, SQL, and Tableau Public to examine healthcare utilization patterns from January 2020 through November 2026.

**Project Highlights**
- Analyzed 3,884 healthcare encounters using SQL.
- Examined annual encounter trends and encounter types.
- Evaluated payer distribution and patient age groups.
- Built an interactive Tableau dashboard to communicate findings.

**Tools:** SQL (SQLite), Tableau Public

**Data Source:** Synthea synthetic healthcare dataset. Data do not represent actual patients, claims, or health system performance.
